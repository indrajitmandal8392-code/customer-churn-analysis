# Customer Churn Analysis

An end-to-end data analytics project focused on analyzing customer churn, identifying churn patterns, and generating business insights using Python and SQL.

## 📌 Project Overview

This project analyzes customer, subscription, and support data to understand customer churn and identify factors associated with customer cancellations.

The analysis includes data cleaning, feature engineering, exploratory data analysis, KPI calculation, churn-risk segmentation, and data visualization.

## 🎯 Objectives

- Analyze overall customer churn and retention.
- Identify churn patterns across subscription plans and regions.
- Analyze customer support interactions and their relationship with churn.
- Calculate key business metrics such as ARPU and revenue at risk.
- Segment customers based on churn risk.
- Generate actionable business insights.

## 📊 Analysis Performed

## 🔍 Key Insights

- Overall churn rate: *28.57%*
- Overall retention rate: *71.43%*
- Basic Plan has the highest observed churn rate: *60.00%*
- Premium Plan has the lowest observed churn rate: *14.29%*
- Support escalation shows a strong positive relationship with churn, with a correlation of *0.77*
